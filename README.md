# Tabela de Estoque
Demostração :  [clique aqui](https://cledsonb.github.io/Tabela-contagem-estoque/)

## Descrição
A Tabela de Estoque é uma ferramenta web que permite aos usuários calcular e gerenciar quantidades de produtos de forma eficiente.

## Funcionalidades
* Carrega uma lista de itens pré definido no arquivo base.txt
* Adicionar produtos à tabela
* Calcular quantidades em diferentes unidades (g, kg, und)
* Filtrar produtos por nome
* Salvar e carregar dados no LocalStorage
* Exportar dados para arquivo de texto

## Como usar
1. Abra a página web em um navegador
2. Adicione produtos à tabela clicando no botão "+"
3. Insira a quantidade do produto e pressione Enter para calcular
4. Clique no resultado para alternar entre unidades
5. Use o campo de filtro para encontrar produtos específicos
6. Clique no botão "Download" para exportar os dados para um arquivo de texto

## Tecnologias utilizadas
* HTML5
* CSS3
* JavaScript (ES6+)
* LocalStorage
